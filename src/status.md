# 翻訳プロジェクトについて

この書籍は、Rust公式書籍『The Rust Programming Language』を、省略せず自然な日本語へ翻訳し、Rust初心者およびC言語初心者向けの比較解説を加えるプロジェクトです。

## 現在の状態

第1章から第10章までを収録しています。第11章以降は、原著の章構成に合わせて後続のPull Requestで追加します。

## 原著

- 原著リポジトリ: [rust-lang/book](https://github.com/rust-lang/book)
- 翻訳基準コミット: [`917544888a55e4da7109bdba8c88c893c0da70f4`](https://github.com/rust-lang/book/commit/917544888a55e4da7109bdba8c88c893c0da70f4)
- Rust Edition: 2024

この日本語版は非公式の翻訳です。Rustプロジェクトおよび原著の著者による公式日本語版ではありません。

## 翻訳と補足の区別

原著の内容は、省略や要約をせずに翻訳します。C言語との比較や初心者向けの追加説明は、原著の本文と区別できる囲み記事として掲載します。
