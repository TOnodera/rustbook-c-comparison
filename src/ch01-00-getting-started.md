# はじめる

Rustの旅を始めましょう！学ぶべきことはたくさんありますが、いかなる旅もどこかから始まります。
この章では、以下のことを説明します:

* RustをLinux、macOS、Windowsにインストールする
* `Hello, world!`と表示するプログラムを書く
* `cargo`というRustのパッケージマネージャ兼ビルドシステムを使用する

> **C言語との比較**
>
> C言語ではコンパイラのほかに、MakeやCMakeなどのビルドツールを別に選ぶことが一般的です。Rustでは、コンパイラの`rustc`に加えて、プロジェクト作成、依存関係管理、ビルド、テストを担当するCargoが標準ツールとして用意されています。
